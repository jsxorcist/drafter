# Drafter - Визуальный конструктор схем

Веб-инструмент для быстрого построения визуальных схем во время живых обсуждений.

## Технологии

- **React 18+** с TypeScript
- **Vite** - быстрый сборщик
- **React-Flow** - библиотека для работы с графами
- **Feature-Sliced Design** - архитектура проекта

## Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

### Сборка для production

```bash
npm run build
```

### Линтинг и форматирование

```bash
npm run lint
npm run format
```

## Структура проекта

Проект следует методологии Feature-Sliced Design:

```
src/
├── app/          # Инициализация приложения, провайдеры
├── pages/        # Страницы приложения
├── widgets/      # Крупные блоки интерфейса
├── features/     # Бизнес-логика и интерактивные компоненты
├── entities/     # Бизнес-сущности (модели данных)
└── shared/       # Переиспользуемые компоненты, утилиты, дизайн-токены
```

## Принципы разработки

- TypeScript без `any`
- ESLint + Prettier для качества кода
- Feature-Sliced Design для масштабируемости
- Единые дизайн-токены через CSS-переменные
- Optimistic UI с откатом
- Минимальные зависимости

## Основные функции

### Управление сущностями
- ✅ **Создание сущностей** - Drag-and-drop из боковой панели, 6 типов сущностей (Процесс, Компонент, Актор, Решение, Данные, Пользовательский)
- ✅ **Редактирование** - Перемещение перетаскиванием, переименование двойным кликом, удаление клавишей Delete
- ✅ **Точки соединений** - 4 точки на каждой сущности (верх, право, низ, лево) с hover-эффектом
- ✅ **Визуальное представление** - Уникальный внешний вид для каждого типа сущности

### Соединения (стрелки)
- ✅ **Создание соединений** - Перетаскивание от одной сущности к другой
- ✅ **Направление** - Стрелки указывают от источника к цели
- ✅ **Автообновление** - При перемещении сущностей соединения обновляются автоматически
- ✅ **Кривизна** - Плавные изогнутые стрелки с настраиваемой кривизной
- ✅ **Множественные соединения** - Можно создавать несколько стрелок между одними и теми же сущностями
- ✅ **Удаление** - Перетаскивание стрелки в пустое место удаляет её

### Текстовые заметки
- ✅ **Создание** - Кнопка в боковой панели
- ✅ **Редактирование** - Inline-редактирование текста
- ✅ **Перемещение** - Свободное перемещение по рабочему полю

### Режим рисования
- ✅ **Рисование** - Свободное рисование мышью на рабочем поле
- ✅ **Настройка размера** - Ползунок для изменения размера маркера (1-20px)
- ✅ **Темная тема** - Автоматическое переключение цвета маркера (белый на темном фоне, черный на светлом)
- ✅ **Изменение цвета** - Существующие рисунки меняют цвет при смене темы
- ✅ **Координаты** - Рисунки привязаны к рабочему полю и не двигаются с камерой
- ✅ **Размер маркера** - Постоянный размер независимо от уровня zoom

### Режим ластика
- ✅ **Точечное удаление** - Удаление рисунков по клику
- ✅ **Точный радиус** - Небольшой радиус для точного стирания
- ✅ **Автоудаление** - Пустые рисунки автоматически удаляются

### Сохранение и загрузка
- ✅ **Автосохранение** - Автоматическое сохранение в LocalStorage при изменениях
- ✅ **Ручное сохранение** - Кнопка "Сохранить" в Toolbar (Ctrl+S)
- ✅ **Экспорт** - Сохранение схемы в JSON файл
- ✅ **Импорт** - Загрузка схемы из JSON файла с валидацией
- ✅ **Восстановление** - Автоматическая загрузка последней схемы при открытии

### Управление интерфейсом
- ✅ **История действий** - Undo/Redo (Ctrl+Z / Ctrl+Y, работает на любой раскладке клавиатуры)
- ✅ **Темная тема** - Переключение между светлой и темной темой
- ✅ **Управление камерой** - Zoom колесиком мыши, Pan перетаскиванием правой кнопкой мыши
- ✅ **Toolbar** - Верхняя панель с кнопками сохранения, экспорта, импорта, переключения темы и справки
- ✅ **Справка** - Модальное окно с инструкциями и сочетаниями клавиш
