# Drafter - Краткое саммари проекта

## Суть проекта

**Drafter** — это веб-инструмент для быстрого построения визуальных схем во время живых обсуждений. Предназначен для менеджеров и продуктовых команд, которым нужно быстро визуализировать идеи, процессы и концепции без сложных инструментов проектирования.

### Основное назначение

- **Быстрое создание схем** во время встреч и обсуждений
- **Визуализация процессов** и связей между элементами
- **Интерактивное построение** диаграмм с минимальными усилиями
- **Прощение ошибок** — интуитивный интерфейс с возможностью отмены действий

### Ключевые особенности

- ✅ Создание и размещение сущностей разных типов (процесс, компонент, актор, решение, данные)
- ✅ Соединение сущностей направленными стрелками с автоматическим обновлением при перемещении
- ✅ Текстовые заметки для добавления пояснений
- ✅ Режим рисования с поддержкой темной темы
- ✅ Режим ластика для удаления рисунков
- ✅ Сохранение/загрузка схем в браузере (LocalStorage)
- ✅ Экспорт/импорт схем в JSON
- ✅ Undo/Redo (Ctrl+Z / Ctrl+Y)
- ✅ Поддержка темной и светлой темы

## Технологический стек

### Основные технологии

- **TypeScript 5.x** (strict mode, без `any`)
- **React 18+** — UI библиотека
- **Vite** — быстрый сборщик и dev-сервер
- **React-Flow 11.x** — библиотека для работы с графами и диаграммами
- **HTML5 Canvas API** — для режима рисования

### Архитектура

- **Feature-Sliced Design (FSD)** — методология организации кода
- **Context API + useReducer** — управление глобальным состоянием
- **CSS-переменные** — дизайн-токены для темной/светлой темы

### Хранилище данных

- **LocalStorage** — сохранение схем в браузере
- **JSON** — формат сериализации для экспорта/импорта

### Инструменты разработки

- **ESLint** — линтинг кода
- **Prettier** — форматирование кода
- **TypeScript** — статическая типизация

│

│   └── diagram/           # Модели данных диаграммы

## Основные функции

### 1. Управление сущностями

- **Типы сущностей**: Процесс, Компонент, Актор, Решение, Данные, Пользовательский
- **Создание**: Drag-and-drop из боковой панели на рабочее поле
- **Перемещение**: Перетаскивание мышью
- **Редактирование**: Двойной клик для переименования
- **Удаление**: Клавиша Delete

### 2. Соединения (стрелки)

- **Создание**: Перетаскивание от одной сущности к другой
- **Направление**: Стрелки указывают от источника к цели
- **Автообновление**: При перемещении сущностей соединения обновляются автоматически
- **Кривизна**: Плавные изогнутые стрелки с настраиваемой кривизной
- **Множественные соединения**: Можно создавать несколько стрелок между одними и теми же сущностями

### 3. Текстовые заметки

- **Создание**: Кнопка в боковой панели
- **Редактирование**: Inline-редактирование текста
- **Перемещение**: Свободное перемещение по рабочему полю

### 4. Режим рисования

- **Активация**: Кнопка в боковой панели
- **Рисование**: Свободное рисование мышью на рабочем поле
- **Настройка размера**: Ползунок для изменения размера маркера
- **Темная тема**: Автоматическое переключение цвета маркера (белый на темном фоне)
- **Сохранение**: Рисунки сохраняются как часть схемы

### 5. Режим ластика

- **Активация**: Кнопка в боковой панели (только в режиме рисования)
- **Удаление**: Точечное удаление рисунков по клику
- **Автоудаление**: Пустые рисунки автоматически удаляются

### 6. Сохранение и загрузка

- **Автосохранение**: Автоматическое сохранение в LocalStorage
- **Экспорт**: Сохранение схемы в JSON файл
- **Импорт**: Загрузка схемы из JSON файла
- **Восстановление**: Автоматическая загрузка последней схемы при открытии

### 7. История действий

- **Undo**: Ctrl+Z (работает на любой раскладке клавиатуры)
- **Redo**: Ctrl+Y (работает на любой раскладке клавиатуры)

## Модель данных

### Основные сущности

1. **Diagram** — корневая сущность схемы
   - Содержит массивы: entities, connections, textNotes, drawings
   - Метаданные: createdAt, updatedAt, title

2. **Entity** — сущность на схеме
   - Тип, позиция, метка, стиль

3. **Connection** — соединение между сущностями
   - sourceId, targetId, метка, стиль, точки подключения

4. **TextNote** — текстовая заметка
   - Позиция, текст, стиль

5. **Drawing** — рисунок
   - Массив strokes (штрихов), стиль

### Сериализация

- Все данные сериализуются в JSON
- Версионирование формата данных
- Валидация при загрузке

## Заключение

**Drafter** — это легковесный, быстрый и интуитивный инструмент для создания визуальных схем. Он идеально подходит для ситуаций, когда нужно быстро визуализировать идею во время обсуждения, без необходимости изучать сложные инструменты проектирования.

Проект следует современным практикам разработки, использует TypeScript для типобезопасности, Feature-Sliced Design для масштабируемости и минимальный набор зависимостей для быстрой загрузки и работы.
